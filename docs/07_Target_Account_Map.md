## PHẦN A — NETWORK VALUE SCORING FRAMEWORK

### A.1 Tại Sao Cần Score Trước Khi Tiếp Cận

> [!TIP]
> **Nguyên Tắc Lựa Chọn Mỏ Neo (Anchor Selection):**
> Không phải tất cả Anchor đều có giá trị như nhau với GOTRACE. Anchor có **Network Value cao** là Anchor kéo được nhiều HTX/nông hộ vào mạng lưới, tạo dữ liệu có giá trị kiểm chứng cao và có thể trở thành Reference Account mở rộng thị trường.

### A.2 Network Value Score (NVS) — 100 Điểm

```
NVS = Network Reach (30đ) + Data Criticality (25đ)
    + Pain Intensity (25đ) + Commercial Potential (20đ)
```

| Chiều | Điểm tối đa | Câu hỏi chính |
|:---|:---:|:---|
| **Network Reach** | 30 | Anchor kéo được bao nhiêu HTX / Supplier / Buyer vào graph? |
| **Data Criticality** | 25 | Dữ liệu Anchor này quan trọng đến đâu cho toàn chuỗi? |
| **Pain Intensity** | 25 | Mức độ pain hiện tại — có urgency không? |
| **Commercial Potential** | 20 | Doanh thu khả năng và tốc độ quyết định? |

### A.3 Chi Tiết Scoring Rubric

**Network Reach (30đ)**
```
Số HTX / Supplier liên kết:
  < 5     →  5đ
  5–15    → 10đ
  16–30   → 20đ
  > 30    → 30đ
```

**Data Criticality (25đ)**
```
Xuất khẩu sang thị trường khó tính (JP/KR/EU):        +10đ
Tham gia 1Mha Program (cần MRV data):                   +8đ
Có buyer downstream yêu cầu truy xuất:                  +5đ
Sản phẩm premium / có certification:                    +2đ
```

**Pain Intensity (25đ)**
```
Đã từng bị từ chối / cảnh báo / đình chỉ xuất khẩu:  +15đ
Đang bị áp lực từ buyer / cơ quan quản lý:             +7đ
Có incident thực phẩm / compliance failure gần đây:    +3đ
```

**Commercial Potential (20đ)**
```
Revenue doanh nghiệp:
  > 500 tỷ VND/năm   → 10đ
  200–500 tỷ          →  7đ
  50–200 tỷ           →  4đ
  < 50 tỷ             →  1đ

Decision cycle ước tính:
  < 1 tháng          →  5đ
  1–3 tháng          →  3đ
  > 3 tháng          →  1đ

Ngân sách IT/Compliance có:
  Có                  →  5đ
  Không rõ            →  2đ
```

## PHẦN I — REFERRAL PROGRAM — LẤY ANCHOR ĐỂ KÉO ANCHOR

### I.1 Referral Mechanism

```
Khi Anchor A hài lòng với pilot:
  1. Hỏi: "Anh/chị có quen ai trong ngành đang gặp vấn đề tương tự?"
  2. Offer: Giảm 1 tháng phí subscription nếu referral thành Diagnostic
  3. Warm intro: Anchor A gửi email/Zalo giới thiệu GOTRACE cho Anchor B

Tại sao Anchor muốn giới thiệu?
  → Nếu supplier của Anchor B cũng dùng GOTRACE → data cross-chain
  → Anchor A nhìn thấy data của supplier đó đáng tin cậy hơn
  → Network effect: Giá trị của Anchor A tăng khi có thêm node trong graph
```

### I.2 Reference Account Program

```
Sau khi Pilot thành công:
  1. Hỏi Anchor có đồng ý làm Reference Account không
  2. GOTRACE cung cấp: Case Study viết sẵn (dùng hoặc không tùy họ)
  3. Anchor có thể chia sẻ: KPI improvement, ROI story
  4. GOTRACE dùng: Anonymized version trong pitch với Anchor khác

Reference = Tier 1 Sales Asset quan trọng nhất
```
